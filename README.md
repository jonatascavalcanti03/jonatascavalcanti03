## 🚀 Projetos em destaque

### 💼 DevJobs — Plataforma de vagas de TI

Plataforma voltada à conexão entre candidatos e empresas, com publicação de vagas, candidaturas e funcionalidades para recrutadores.

- Sistema de vagas e candidaturas.
- Área para empresas e recrutadores.
- Exploração de planos premium e monetização.
- Integração de pagamentos com Stripe.

**Tecnologias exploradas:** Next.js, React, TypeScript, PostgreSQL, Supabase e Stripe.

### 🌐 TechFlow — Site de tecnologia

Projeto web com foco em design moderno e experiência interativa.

- Interface com efeitos visuais.
- Cards interativos e animações.
- Rolagem suave e modo escuro.

**Tecnologias:** HTML5, CSS3 e JavaScript.

### 💰 Controle Financeiro

Aplicação web para acompanhamento de receitas, despesas e orçamento mensal.

- Registro de receitas e despesas.
- Organização por categorias.
- Visualização de informações financeiras.
- Persistência de dados.

**Tecnologias:** Python, Flask, SQLite e Bootstrap 5.

### 🛍️ Brechó de Luxo — SaaS em desenvolvimento

Projeto voltado ao comércio eletrônico de produtos de moda.

- Experiência de compra online.
- Integração de checkout.
- Controle de estoque.
- Efeitos visuais para produtos.

**Tecnologias:** Next.js, TypeScript, Prisma, Stripe e Tailwind CSS.

### 📈 Kiwify Boost — SaaS em desenvolvimento

Projeto para acompanhamento de vendas e campanhas de marketing.

- Painel de acompanhamento de vendas.
- Exploração de integrações com plataformas de anúncios.
- Gráficos e indicadores.
- Exportação de relatórios.

**Tecnologias:** JavaScript, Node.js, Express, Chart.js e Anime.js.

### 🔊 AutoSound Pro — SaaS em desenvolvimento

Projeto que explora ferramentas de áudio automotivo no navegador.

- Processamento de áudio em tempo real.
- Recursos baseados na Web Audio API.
- Interface web especializada.

**Tecnologias:** Next.js, TypeScript, Web Audio API e Tailwind CSS.

### 🎓 Trilha Smart — Plataforma educacional

Projeto voltado à experiência de aprendizagem em ambiente digital.

**Tecnologias exploradas:** Next.js, React, JavaScript e CSS.
